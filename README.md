This repository contains the numerical data and an example simulation script associated with the manuscript:

**Hydrophobic Patch Spacing Produces Nonmonotonic Compaction in Disordered Proteins**

Henry Silvernail, Wangfei Yang, and Wenwei Zheng

`Rg_data.xlsx`: Numerical radius-of-gyration data and associated statistical uncertainties, organized according to the figures in the main text.
